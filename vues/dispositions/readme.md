# Dispositions

Le classeur `azerty-dcs.ods` contient :

* la disposition de l’AZERTY DCS dans les onglets `kbfrdcs` et `kbfrdcs‑VerrCap`
* une variante retouchée encore plus utilisable dans l’onglet `kbfrFRs`

## Consultation

1. Accéder à la page du fichier `azerty-dcs.ods`
2. Cliquer sur « View raw »
3. Récupérer le fichier dans les téléchargements
